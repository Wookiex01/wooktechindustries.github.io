Use of Your Personal Data

Local Data Storage and Offline Architecture

Player Capital Master is deliberately engineered as an offline-first utility. All user budget entries, numeric ledger allocations, profile schemes, and transaction histories are written strictly to Your device's internal secure storage and are never transmitted to, viewed by, or stored on Wook Tech Industries' servers.

User-Controlled Import & Export (Pro)

Pro users may manually export Your ledger as a JSON or CSV file and import it back later. Export files are written to Your device's chosen location (e.g., the Downloads folder, or a directory You select via Android's Storage Access Framework) and never pass through Wook Tech Industries' servers. The Company does not host, control, or retain copies of these export files. Any subsequent storage, sharing, or transmission of those files is solely under Your control.

WTI Zero-Leak Data Protocol & Broker Ban

Wook Tech Industries LLC operates under a strict data integrity mandate. We do not sell, lease, trade, or share personal user data, application logs, or financial tracking schemas with third-party data brokers, advertising aggregators, or outside marketing entities.

The Company utilizes collected data strictly for the following functional purposes:

  • To maintain the Service: Monitoring system crashes and troubleshooting database bugs to ensure application stability.
  • To manage Your Account: Authenticating user access parameters for secure internal operations.
  • To communicate updates: Delivering critical security notices, version update logs, or core functional changes directly related to WTI services.

Data is explicitly blocked from external distribution except in the following limited, operational conditions:

  • With Explicit Consent: Data may be transmitted only if You explicitly opt in to facilitate an optional, user-requested integration.
  • With Contractually Compliant Service Providers: We may share minimal transactional parameters with verified platforms (e.g., RevenueCat) solely to validate application licenses. These infrastructure partners are contractually required to maintain the exact same strict privacy boundaries and are legally banned from distributing WTI user details.
